# ESP32-S3 LCR Meter

## Description
A fully functional LCR meter (Inductance, Capacitance, Resistance) built around the ESP32-S3. The system uses Digital Signal Processing (DSP) to calculate component values by analyzing the voltage and phase differences across a known reference resistor and the Device Under Test (DUT).

## Features
- **Custom Sine Wave Generation:** Utilizes a 100 kHz PWM signal filtered into a clean 1 kHz sine wave stimulus.
- **Precision Sampling:** ADC sampling runs at 20 kHz on a dedicated FreeRTOS task pinned to Core 0, eliminating OS jitter.
- **DSP Architecture:** Implements the Goertzel algorithm for efficient single-bin Discrete Fourier Transform (DFT) amplitude and phase extraction.
- **Adaptive Hybrid Filtering:** Uses a custom median filter with a dynamic phase target to compensate for physical component imperfections (like ESR/DCR) and hardware noise.
- **Standalone Operation:** Real-time classification and measurement display on an LCD1602 screen (4-bit parallel interface).
- **Robust Error Handling:** Automatic hardware-level detection for missing components, open circuits, or powered-off op-amps.

## Circuit
- **Generator PWM:** PWM signal at 100 kHz generated by the ESP32-S3.
- **Vin:** Filtered sine wave (1 kHz) after the RC low-pass filter, passed through an LM358 voltage follower buffer; acts as the input to the voltage divider.
- **Vout:** Output signal from the voltage divider (across the DUT), also buffered through the LM358 to isolate the ESP32's ADC impedance.
- **Impedance Calculation:** DUT impedance is derived from the voltage ratio (Vout/Vin) and the phase difference between the two signals.
